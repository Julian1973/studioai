# Creative Directing Standard v3

This is a forward-only production standard. Existing approved media and legacy department
records remain valid. A scene newly authored by `cb_creative.run_scene()` is stamped with
`creativeDirectingStandardVersion: 3`; only those packages activate the requirements below.
The locked v2 runtime skill files remain byte-for-byte unchanged. Version 3 packages route to
separate `*-v3` Director, Cinematographer, DP and Seedance Production Director contracts, so a
software upgrade cannot invalidate a legacy canon approval.

## Required Flow

1. The Creative Room completes Gates 0-6 and produces typed emotion, comedy, cinematography,
   performance and performance-budget contracts.
2. Julian approves the storyboard. Handover hash-binds every selected shot card into the
   canonical production package.
3. Cinematography may prepare SEE only from that approved, current card.
4. Voice Direction and the approved voice asset establish actual cadence and timing.
5. Before Animation Direction, the engine measures occupied dialogue time against the
   Director's reserved silent acting and landing time. An overloaded unit returns for a
   story-led split before any provider call.
6. The local voice-timed scene slate is built and reviewed. Julian must explicitly approve
   its dialogue position, breathing room, reaction and landing rhythm.
7. WATCH preflight reports prompt contract completeness. The score proves required instruction
   coverage only; it is not an artistic-quality score.
8. Returned media receives intended-versus-observed dailies review for emotional landing,
   comedy construction, acting, contact, weight, physics, camera, continuity and finish.

## Walk-Forward Rule

No migration rewrites an old package or approval. To bring an existing scene onto v3, rerun its
Creative Room design, review the new storyboard, approve it, and promote only the selected shot
cards. The resulting package revision invalidates prior prompt/spend bindings through the
existing lineage mechanism; it does not alter approved source media.
