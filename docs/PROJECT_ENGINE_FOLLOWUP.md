# Project engine follow-up

The Crystal Bears release qualifies the Native adapter only. The Project
engine remains outside paid production qualification.

Known open work:

- Project WATCH preparation can invoke Keyframe Director and Prompt Director
  model paths instead of compiling the approved DIRECT/SEE/HEAR state
  deterministically.
- Project Journey late-result and retry tests do not reach provider lifecycle
  assertions because their fixtures stop at stricter current-candidate and
  reference preconditions.
- The Project engine must use the same sealed request, reservation, duplicate
  protection and reference-resolution contract before paid production.

**No paid Fire on wizard-created or Project-engine projects until this follow-up
is complete.**

The Journey acceptance/spend tests are therefore excluded from the Native
push gate. Their lifecycle assertions remain required for the Project-engine
qualification pass and are not evidence that Crystal Bears Native is unsafe.
