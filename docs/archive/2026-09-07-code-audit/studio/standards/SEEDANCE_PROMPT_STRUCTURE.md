# Seedance Prompt Structure

Use the smallest structure that makes the production unit playable. A continuous
take does not need artificial shot labels; a multi-shot unit names only intentional
cuts.

## Order

1. Format and verified request assumptions
2. Operation and opening authority
3. Reference-role contract
4. Approved audio authority
5. Opening geography and state
6. New dramatic beat
7. Motivated camera, action, performance and production detail
8. Surgical safeguards for likely failures only
9. Exact landing picture and sound

Write visible causes and effects in present tense. Give each subject a clear action,
tie camera movement to a subject and trigger, and make reactions follow their cause.
Use lens language only when it creates a distinct result. Identity and location
appearance belong to approved references rather than descriptive reconstruction.

The prompt must expose the Heart Director's intended audience experience through
observable behavior. Terms such as `beautiful`, `cinematic`, `award-winning` or a
filmmaker's name do not constitute direction.

Apply the 20-point gate in
`skills/seedance-production-director/references/quality-gates.md`. A passing score
does not approve media and cannot replace human review.
