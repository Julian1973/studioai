# Director output handoff verification

The Studio persists department output on the shot continuity ledger under departmentWork. The selected direction is compiled into provider requests; a completed skill invocation alone is not evidence of delivery.

The current-path integration test now puts distinctive audience intent, camera, lighting and anticipation-pose decisions into a persisted cinematography record, then runs keyframe generation through mocked provider boundaries. Both image request payloads must contain those exact decisions. It also verifies each saved animation direction's observable performance and landing image reach its video request, in addition to the existing exact compiled-prompt comparison. The isolated sequence continues through approvals and an assembled master.

Result: 65 passed, process exit 0, across current production path and department tests. All providers were mocked. No production records, approvals, media or spending were changed. No runtime wiring defect was established by this check, so this change strengthens regression evidence rather than adding another runtime gate.

Runtime skill loading was traced to the shared production standard and marked department contracts. Fresh skill prose does not retroactively rewrite already approved direction. Inside the Studio, newly prepared direction uses the current guidance; a standalone Codex skill response is not automatically imported into a production package.

This establishes transport of tested creative decisions into prompts. It does not prove that an image/video model will execute them correctly or that the resulting scene will achieve the desired emotional quality. Human SEE, HEAR and WATCH reviews remain the evidence of those outcomes.
