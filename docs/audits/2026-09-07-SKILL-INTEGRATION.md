## Learning now connected

Successful approve/reject operations for voice, keyframes and animation record evidence,
including original feedback, episode/scene/shot, source version, cast and media pointers.
Bounded WATCH feedback is also captured. Failed decisions do not generate acceptance evidence.
Capture uses a file lease and atomic replacement; stable decision identities avoid duplicate
records for identical saved state. Learning errors do not overturn a saved media decision.

The creative scene pass retrieves at most four relevant observations, frozen for that run.
Look, cinematography, voice and animation preparation receive the same kind of bounded
context. Exact shot and scene matches rank first; shared cast can carry feedback into a later
scene of the same episode. Provider faults, bare verdicts and unrelated episodes are excluded.
Conflicting observations remain available. The worker is asked to explain useful application
in an existing rationale field with the evidence ID. Prepared department records retain the
observations supplied; long shot context cannot truncate them away.

This changes contextual learning, not model weights. Cross-episode canon/principle promotion
remains explicit and versioned. Existing recorded evidence is eligible when it has sufficient
scope; no historical feedback or reasons for bare approvals were invented. The system does
not claim that merely retrieving an observation proves an improvement in artistic quality.
