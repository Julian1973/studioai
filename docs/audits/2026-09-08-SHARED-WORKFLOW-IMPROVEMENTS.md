# Shared Studio workflow improvements

Scope: project-agnostic production software. No live project, episode, canon, credential or approved media was changed. No paid generation or editor execution was performed.

## Direction and references

SEE now has an explicit single-opening-frame contract. Performance, ending state and timed beats remain available as context that must not be depicted as successive poses. WATCH receives the timed motion direction. Both retain intent, geography and reference authority. Each new SEE/WATCH saves a direction trace; the emitted prompt contains the corresponding structured contract. The existing tests verify revised performance reaches generation without replacing approved voices or other shots.

The director receives earlier approved scene/camera reference choices with exact candidate IDs and hashes, plus available reference images within the existing eight-image bound. Existing reference validation distinguishes a matching camera setup from a geography anchor. A reverse view can use a scene anchor without pretending it is the same camera. This does not auto-generate speculative coverage or certify rendered geography.

## Chat and learning

Unambiguous phrases such as “apply the change”, “discard the change”, “undo the last change” and “approve and continue” use the same commands as buttons. Applying requires the current preview ID and still prepares a candidate for human review. General creative language remains with the model and returns a scoped proposal.

Users can save an advisory lesson against an exact approved SEE, HEAR or WATCH, and retire it without deleting evidence. Active lessons stay within the project and retain source files, signatures, stage and episode. Missing evidence is excluded from future direction. Raw approval/rejection feedback is labelled separately from human-approved learning. Keys are rejected in learning text.

## Forecasts

Project services accept optional account-specific unit rates: per image, per 1,000 voice characters, or per video second. Reservations use the larger of the configured request floor and unit forecast. WATCH uses its reviewed duration; HEAR includes every line and delivery tag. Shot, scene and episode forecasts describe one candidate per missing outcome, excluding future revisions and optional review. Unknown rates remain explicit. Repeat generation job counts include failed attempts and are not presented as provider charges.

## Finishing returns

Create finishing handoff still prepares FCPXML and the source-bound brief; it does not dispatch Resolve. A returned MP4/MOV/WebM saved within the selected project can now be registered with the current handoff ID, file SHA-256, Resolve project/timeline IDs, inspected ranges and unresolved work. Import verifies decoding (and an audio stream when dialogue exists), copies to a separate candidate and keeps source shots untouched. Returned/source running times are visible. Editor inspection evidence is self-reported, not independently proven.

Human approve/reject is tied to the exact copied file and current assembly/handoff. Missing, changed, cross-project and obsolete files are refused. Declared unresolved work prevents approval. No delivery publication or broadcast certification is implied. UI polling preserves finishing form entries and the returned player.
