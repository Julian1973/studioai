# Shot coherence operating contract — 1.0

Agreed with Julian: reconcile the current shot before writing provider instructions.

The authoritative version contains approved events, acting, camera coverage, incoming and outgoing state, references, and measured audio. Superseded versions are history. A source conflict returns to director preparation; final review cannot invent a new event to reconcile it.

The source-plan AI review checks view-to-view object count, holder, location, support, visibility, cause and timing. The final Prompt Director separately checks the actual compiled request. A permitted visual correction must be reviewed again. Audio and approved events remain protected. The final payload hash binds the reviewed prompt, authorities, references, audio, duration and settings; changed inputs cannot reuse the review.

Rejections remain in the prompt bank with exact prompt hash and batch. Same-shot failures are supplied to preparation and final review. Later decisions link earlier rejections. Neither a score nor general approval marks a lesson validated. Failure-specific returned-media evidence is required before claiming the correction worked; shared-practice promotion remains a separate human decision.
