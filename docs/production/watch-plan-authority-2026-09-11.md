# WATCH plan authority and deterministic emission

The final WATCH provider text is emitted by `studio_seedance_execution.compile_prompt` from `studio_watch_plan.WatchPlan`. Historical `seedancePrompt`, specialist `providerPrompt` and source prompt visual sections are not creative inputs to this emitter. Native specialist fields supply the current executable camera, action, acting and landing; the approved Director Card remains the source authority against which those fields are reviewed. Project requests project their current typed Director Card directly.

The adapter copies existing timed views, scoped references, opening/landing, exact dialogue occurrences and approved audio into a request-local plan. It does not infer equal view durations or derive creative action from provider prose. `watchPlanBinding` records the plan hash, authority hash and the exact reference/audio/duration/settings binding. Existing native preflight prompt preparation remains an audio-compatibility and preview path; it cannot bypass the final plan compiler and its verification.

Per-view visibility resolves exact registered character names and entity IDs without case sensitivity: native `char:aida` and plain `Aida` both bind the actual Aida identity slot. Props and unknown entities do not become cast. An explicit empty list emits no characters; missing visibility emits no cast constraint. The read-only S2.SH1 qualification confirms Aida at `@图2` in views 1, 4 and 5, with no physical characters in the two water-surface views.

Prompt Director always reviews the source plan first. A correction targets a complete emitted `/specialist/...` typed field, supplies its exact expected value and plan hash, and cites an existing `/shot/...` source field and digest. The correction updates the request-local originating specialist field and rebuilds the plan. It never edits the approved scene package, Director Card, audio, identity bindings or delivery contract. The revised plan receives another semantic review and a new deterministic emission before exact-payload review. Two revisions are allowed; unresolved corrections block the request. Legacy prompt-string edits are rejected. Neither string validation nor these tests proves semantic model detection or film quality.

Project dialogue is bound from the approved HEAR recording's hash and measured input-indexed timestamps. Repeated words remain distinct occurrences with stable shot/line IDs. Exact words appear once, with their speaker and measured interval. The existing Audio1 provider block is preserved byte-for-byte; the project adapter gives it a dedicated `[Audio]` boundary and no longer appends raw timing JSON. When a legacy comparison Audio block already contains a spoken marker, it stays there once and the typed occurrence record binds it to the correct view and interval.

An explicit transport segment selects whole authored coverage views using `globalStartSec` and `globalEndSec`. Its local numeric clocks and line indexes are rebased against a source-bound Audio1 slice. `authorities.sourceUnit` preserves the complete original shot and specialist, their hashes, source view indexes and dialogue occurrence mapping. Completed entry state is carried without replaying its cause. Boundaries through a view, spoken occurrence or sound/channel event require an explicit revised split; they are never silently trimmed. Missing scope or unsupported prose-only requests are archived as blocked, without a model or media call. Historical approved media and packages are unchanged.

Qualification uses injected semantic reviewers and synthetic media with network connections forbidden. Tests cover both native and project request-to-Fire routes, exact archived/sealed/recompiled output parity, typed correction convergence, stale-source and altered-contract rejection, immutable audio/word/speaker/timing preservation, and two-segment parent truth/local-clock continuity. The existing 9.5 quality floor is unchanged. No tests confer visual approval, auditory approval, spend authorization or creative success.
