## Problem and resulting behaviour

Critical view records without timing or visibility previously fell through to READY with an unverified note. They now block sealing unless the start can be derived from an explicit authored numeric interval. Every such repair records its source path, original interval and derived value. Prose, view order and model guesses are not timing authority. Incomplete critical state-change records and omitted critical visibility also block.

The previous dynamic resolver also required a future matching image for every critical state revisit. Authoritative intended state now carries through scoped historical, opening and identity references without requiring a pre-generated picture of the future. A reference claiming current-state authority at that time still blocks if contradictory or unverified. Intended state is never presented as an observed or approved render outcome. Dialogue and audio remain untouched.
