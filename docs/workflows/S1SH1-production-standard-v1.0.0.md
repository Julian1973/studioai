# S1.SH1 production workflow standard — 1.0.0

Status: adopted operating reference; visual and auditory outcomes still require human review.
Scope: all projects, episodes and shots. Crystal Bears Ep3 S1.SH1 is evidence for the process, never a reusable prompt, cast, setting, camera setup or performance.

## Production sequence

1. Intake preserves exact spoken words separately from action. A word correction does not create a human performance override. Preserve explicitly authored performance overrides.
2. SEE binds the planned opening cast, required prop designs, scene geography and any deliberately selected composition reference. Each reference has a stated role. Characters entering later are not automatically put into frame one. Missing files are surfaced by the existing preflight, not silently omitted.
3. The opening depicts one instant. Record shot-specific positions, relative scale, distance, target and camera separately from the later action. A still reference does not prove motion continuity.
4. After feedback, preserve accepted elements. For local identity drift, prefer a local revision with that character's original identity reference. The last accepted/reviewed composition supplies staging, not replacement identity. A changed image remains a candidate until selected and approved by the director.
5. Preserve the exact chosen image in shot-owned storage and record human approval. External image-tool trials must be imported through the Studio's source-selection and approval path; a chat approval alone is not a production record.
6. HEAR exposes the voice player when present, then exact spoken words and provider performance text above operational detail. The Voice Director must translate acting into its performance recipes and voice settings. Prose notes are not ElevenLabs inputs. Check the compiled input and identify stale audio after edits.
7. Isolated audio lines must not borrow audio handles from neighbouring concatenated parts. Preserve short edge fades and natural speech. Do not claim smoothness from tests alone; review the returned bed.
8. WATCH uses approved SEE and HEAR with the shot-specific action, camera and continuity handoff. Revisions preserve source and approval history. Finishing follows the existing Resolve post-supervision skill and its evidence requirements.

## Runtime implementation

- `studio_reference_contract.py`: shared version, planned opening cast, idempotent identity-slot completion and reference receipts.
- `cb_render.py`: SEE display and provider attachments share that completed reference blueprint. Explicit prop requirements retain their existing provider-slot binding. Human performance overrides are created only when actually supplied.
- `cb_gen.py`: Seedream outputs retain the exact prompt, local input hashes, output hash and model in `.reference-contract.json`. Remote references are marked remote without persisting signed URLs.
- `studio_production.py`: multi-project jobs retain reference receipts alongside existing project-local asset validation and source lineage.
- `cb_departments.py`: Voice Director instructions explicitly distinguish provider performance recipes from prose metadata.
- `cb_audio_timing.py`: isolated source boundaries prevent neighbour leakage, with edge fades preserved.
- `cb-studio/app.html`: HEAR artefact order is stable with and without a take.

## Evidence and limits

The approved example is recorded in `cb-output/image-trials/Ep3_S1_SH1_chat_image_final_approval.json`. Trial files preserve the intermediate prompts and references. Those rejected/intermediate images are not canon.

The original SEE trial and individual bee edits used an external image tool, then the selected output was imported and approved. That conversational editing loop is not yet a single integrated Studio provider action. The two production engines remain separate; this standard is not a claim that their provider connectivity has been unified.

Existing approved shots are not rewritten or regenerated by adoption. No provider calls are required by a version update. No automatic batch generation, cross-project asset borrowing or automatic media approval follows from this standard.
