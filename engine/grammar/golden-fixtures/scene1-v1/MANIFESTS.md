# FIXTURE MANIFESTS — the structural elements each emission must contain

A fixture passes only if every element below is present in the compiler's
output. These are mechanical string/pattern checks, not opinions.

## beat_1_chase — false-triumph-chase
- [ ] 4 shots, each named, each ending "End state: <describable frame>"
- [ ] Shot 1 contains three parallax speeds (foreground / midground / distant)
- [ ] Shot 1 names at least two landmarks the subject passes
- [ ] Shot 1 contains subject scale change ("pulls ahead and shrinks" + "camera
      surges")
- [ ] Shot 1 contains a foreground wipe across the lens
- [ ] Shot 2 contains three separated contacts with increasing consequence
- [ ] Shot 2 ends at maximum load, before release
- [ ] Shot 3 is the compound aerial alone, camera tracking the full arc
- [ ] Shot 4 contains the self-check BEFORE the pride
- [ ] Shot 4 dialogue inside the beat, with delivery direction
- [ ] Shot 4 pose holds a full beat after the line
- [ ] Shot 4 ends on the held cut to the non-acting character
- [ ] Staging: acting character frame-left, witness frame-right
- [ ] No `no cuts` and no `no handheld` exclusion
- [ ] No field restates the shot plan's action

## beat_2_moustache — reveal-and-deadpan-verdict
- [ ] ATTRIBUTE OWNERSHIP block naming owner and excluding all others
- [ ] Opening state declares the feature is NOT yet present
- [ ] Shot 1 arrival is overcommitted (launch too hard / overshoot / arrive
      faster than he can stop) — never "crosses to" or "with control"
- [ ] Shot 1 cuts before the result is visible
- [ ] Shot 2 is the reveal in close-up with the presenting beat
- [ ] Shot 3 restates the non-owner's clean state
- [ ] Shot 3 eye-line travels to the feature and back before the line
- [ ] Shot 3 micro-tell precedes the line
- [ ] Hold after the line
- [ ] End state names the frame to harvest

## beat_3_crash — escalation-into-verdict
- [ ] ATTRIBUTE OWNERSHIP block present
- [ ] Opening state matches the previous unit's declared end state exactly
- [ ] The correction visibly worsens the problem
- [ ] The character sees the evidence on themselves before panicking
- [ ] Contacts separated and increasing
- [ ] The button lands and holds before the line
- [ ] The cut to the reactor comes only after the line has finished
- [ ] The reactor's turn names both states and the movement between them

## beat_4_storm — environment-turn
- [ ] Environment reference declared as TWO states with identical geometry
- [ ] The world changes BEFORE any character reacts (explicit ordering)
- [ ] Vegetation posture changes, not only light
- [ ] The denier's physical betrayal precedes their cover line
- [ ] The reader stills and listens as a real beat, not a glance
- [ ] Hold after the quiet line
- [ ] Final hold with no movement, then fade
