# The Box Monsters — a StudioAI project

Created from `studio/templates/project/` (T56). Everything the studio knows about this show lives in
this folder and nowhere else: `profile.json` (the only path authority), `canon/` (who and where —
facts), `laws/` (the show's own rules the engine enforces), `chairs/` (the show's taste overlays for
the studio's generic chairs), `creative/` (learning, the Design-tab roster), `episodes/` (scripts,
the episode index, every emitted package and take), `assets/` (turnarounds, plates, references).
The engine and the studio UI are shared with every other project and contain none of this show.
