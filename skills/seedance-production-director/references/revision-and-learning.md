# Scoped revisions and useful learning

Keep scene, shot, beat and occurrence IDs stable. Before applying a correction, identify
which current inputs it changes and which derived artifacts consume those inputs.
Rebuild only those derivatives inside the requested scope. Preserve all prior accepted
media and all unaffected approvals. A new version is a candidate until reviewed.

For a dialogue edit, update the source occurrence and affected performance/animation work;
keep unrelated imagery, sibling shots and other scenes. For a visual or performance edit,
keep unchanged dialogue/audio. If the outgoing handoff changes, show the continuity impact
on the next shot as a proposal. Never claim later shots are unaffected without checking
that boundary; never automatically replace their approved versions.

Capture human decisions with episode, scene, shot, source version, media pointers, verdict
and exact feedback. A bare approval records evidence but does not identify what caused success.
Distinguish a provider fault from a creative criticism. Retrieve a small set relevant to the
current shot, scene or shared characters in the episode, with evidence IDs and original scope.
Consider contrary evidence and apply only what suits the current script. Explain an application
in an existing rationale field so the next review can judge whether it helped.

An observation may inform a creative candidate without becoming a hard rule. Broader canon
changes stay explicit and versioned. Learning does not rewrite earlier prompts or approvals,
and collecting feedback alone is not proof of improved film quality.
